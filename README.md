# CAPTCHA HUMANO — 10 Fases

Jogo de verificação humana em 10 fases variadas. Prove que você não é um bot.

**Jogar agora:** https://detiillimichel-max.github.io/captcha-game/

## Como jogar

Você tem 3 vidas. Errou = -1 vida. Zere as vidas = Game Over.

Fases:
1. **Memória Flash** - Repita a sequência de cores
2. **Ache o Intruso** - Toque no emoji diferente
3. **Quebra-cabeça Deslizante** - Ordene os emojis
4. **Pipa Camaleão** - Memorize a 2ª cor da pipa
5. **Sticker Correto** - Selecione o sticker pedido
6. **Reação Rápida** - Toque quando ficar VERDE
7. **Repita o Padrão** - Memorize a sequência de setas
8. **Conte os Objetos** - Quantos 🐟 você viu?
9. **Pares de Memória** - Encontre todos os pares
10. **Chefe Final** - Mix de 3 desafios rápidos

## Recursos

- 100% HTML/CSS/JS em 1 arquivo
- Sem vídeos, sem CDN externo
- UI Glassmorphism premium
- Salva recorde no localStorage
- Responsivo mobile/desktop
- Teclado: setas funcionam na Fase 7

## Instalação

1. Faça upload do `index.html` na raiz do repo
2. Ative GitHub Pages em Settings > Pages > Branch: main / root
3. Acesse 

## Personalização

Edite o objeto `phases` no script para trocar perguntas, emojis e dificuldade.
